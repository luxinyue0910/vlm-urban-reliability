# 模型试跑记录与限制

10 张全景图、七类设施，共 70 项有效模型输出。模型请求及返回名称均为 `qwen3.8-flash`，temperature=0，关闭 thinking；每张原图一次成功请求，没有裁剪或对比度处理。

此次不公开初始人工标签、基于这些标签的人机对比、置信度与错误关系或暂定复核结果。当前人工试标不作为正式真值，因此不报告模型准确率，也不能据此评价 RQ3 的错误筛查能力。

运行共记录 55,967 token（输入 52,660，输出 3,307）；没有归档实际账单金额。公开 records 保留模型、时长、usage、预测及哈希，省略服务请求 ID 和原始图片名；本地完整原始响应另存。

完整 Prompt 包含队友的 PDF 正文，未公开。`run_manifest.json` 中 Prompt/PDF 哈希对应历史实际运行；`build_prompt.py` 使用本地 PDF 重建并检查 Prompt 哈希。不同 PDF 或提取器版本可能得到不同文本，不能静默当作原试跑设置。

图片按场景条件有目的选择，部分来自同一视频，不能据此估计整个数据集的总体表现。七类任务是同一张图上的相关判断，不能当作 70 张独立图片。正式实验仍需固定标注标准、取得可靠参考标签并划分独立数据集。
