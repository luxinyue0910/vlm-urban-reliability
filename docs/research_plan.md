# 当前实验范围与待完成部分

版本说明：下文保留七类 V1 阶段的研究方案。最新六类基础 Prompt 的范围与状态见[六类版本说明](base_v2_six_tasks.md)；此页中的七类任务数和试跑进度不是最新执行配置。

当前试跑采用七类设施、10 张图、主模型 qwen3.8-flash。114 张图片是现有候选数据，不等于已经完成的独立测试集。10 张图按困难条件有目的选择，部分来自同一视频；正式划分需避免同街道、近邻图片跨组泄漏。

## RQ2：保留六组

| 组别 | 输入 | 对照目的 |
|---|---|---|
| A | 原图 + 基础 Prompt | 起点；当前 Prompt 属于初始试跑版本，正式 A/B 尚未冻结 |
| B | 原图 + 证据约束 Prompt | B 对 A 看 Prompt 作用 |
| C | 原图与局部图 + B 的 Prompt | C 对 B 看裁剪辅助 |
| D | 调对比度全图 + B 的 Prompt | D 对 B 看对比度 |
| E | 调对比度全图与局部图 + B 的 Prompt | E 对 C/D 看叠加收益 |
| F | 按图像条件选择 B/C/D/E 的处理方式 | 对比开发集选定的最佳固定处理 |

B–E 是裁剪 × 对比度的 2×2 消融；A/B 是 Prompt 对照。六组不是完整的 Prompt × 预处理交叉实验。所有组使用相同图片、标签、模型和固定推理设置。局部图和全图一起输入，定位失败退回全图。E 沿用 C 在原图上的框；不做生成式补图。

开发集确定处理参数、路由规则和最佳固定组；测试集只做冻结后的比较。分别报告改对、改错、整体收益和条件性收益；不因处理后答错就断言处理是原因。保存裁剪框、质量分数、分支和回退情况。目前这些处理分支尚未实现。

## RQ3–RQ4

比较 confidence、原图质量、二者结合三种风险。Confidence 风险可取每图七任务最低 confidence 的 1−score/100；质量风险用偏暗和模糊程度；具体算法在开发集固定。组合先用等权平均。校准集定门槛，独立测试集检查识别错误能力；筛查本身不使用该图人工真值。NA 单独报告，也应比较只筛 NA 的简单基准。

复核按图选择，每张检查七类任务。相同预算下比较三种风险优先、随机复核和知道真值的理想上限。模拟用真值替换所选图片答案，明确假设人工完全纠错；另外测实际人工用时与改错情况。不能把研究阶段完整标注的成本说成已经省掉了。

## 数据与指标

历史计划暂定试跑 20、开发 200、校准 200、测试 800 张；这些不是现有样本量，也不是已验证足够的样本量。当前仅完成 10 张模型试跑和非正式人工试标；人工试标暂不公开，也不作为正式真值。正式规模需要根据数据、类别和希望检测的差异再确定。

有最终人工真值的 N 张有效图、每图七任务时，总判断数为 7N。报告：

- 三分类一致/准确率：正确判断数 ÷ 7N；逐任务分母为 N。只有正式裁决后的参考标签才称准确率。
- 纠错与新增错误：原错后对 / 原对后错的数量分别除以 7N。
- 无依据肯定：人工 0、模型 1 数 ÷ 人工 0 数；漏检：人工 1、模型 0 数 ÷ 人工 1 数。
- 人工可判 0/1 中，模型明确作答数 ÷ 人工可判数；其错误数 ÷ 明确作答数。覆盖与错误率同时报告。
- 错误图：一张图至少一任务错；捕获率 = 选中错误图数 ÷ 全部错误图数；筛查精确率 = 选中错误图数 ÷ 选中图数；另报 AP。
- 复核后残余错误率 = 仍错判断数 ÷ 7N；复核比例 = 复核图数 ÷ N。质量达到预定目标后才讨论省工。

分母为零记不可计算。持续输出失败不删样本。相同图片配对比较，按街道/来源考虑相关性；同图七任务不当成七张独立图片。RQ1 只能从观察数据分析关联。

## 仍开放的标注边界

自行车道的明确分隔与普通路侧通道、人行道与铺砖停车区、远处标志只需识别类别还是需要细节、0 与 NA 的观察范围。现阶段保留初始标签和分歧，不把暂定 AI 建议写成最终真值；暂不联系团队确认。
